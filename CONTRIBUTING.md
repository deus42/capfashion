# Contributing

Thanks for helping. Capsula is small and opinionated: for anything bigger than a fix, open an issue first so we can agree on the approach.

- Setup, layout and rules are in [AGENTS.md](AGENTS.md), written for people and coding agents alike, and in [app/README.md](app/README.md).
- Run `cd app && npm run check` before opening a pull request, and add a test for new server behaviour.
- Keep to the design rules: minimal screens, no side panels, no hidden content.
- Every new Ukrainian interface string needs its English version in `app/src/i18n/en.ts`.
- Never put real photos or personal data in issues, tests or screenshots.
- Report security problems as [SECURITY.md](SECURITY.md) describes, not in public issues.

Contributions are accepted under the project's license, [AGPL-3.0-or-later](LICENSE). There is no CLA, so you keep the copyright to your changes.
