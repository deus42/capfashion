## Ідея

Більшість застосунків для гардероба лише складають каталог того, що вже є. Capsula починає зі **стилю**.

В основі — капсульна традиція: від взаємозамінних речей Claire McCardell 1930-х, через лондонський бутик *Wardrobe* Susie Faux 1970-х, до «систем одягу» 1980-х. Капсула — це невеликий закритий набір речей навколо бази, з однією палітрою, де майже будь-який верх пасує до будь-якого низу. Нові образи народжуються з поєднань, а не з нових покупок.

Capsula робить із цього щоденний інструмент:

| | |
|---|---|
| **Капсули** | Окремі стилі, як-от Smart Casual, Mediterranean Casual чи Outdoor Casual, кожен зі своєю палітрою, матеріалами й погодою. |
| **Закритий набір** | Десять речей одягу, до трьох пар взуття й трьох аксесуарів — із того, що є, і того, що варто купити. Одна-дві базові речі тримають усе разом. |
| **Образи** | Лише з речей набору, з чесною оцінкою. Майже однакові образи зведено в один, а Capsula пам'ятає, від чого ти вже відмовився. |
| **Примірка** | Побач образ на собі. Обличчя й статура беруться лише з твоїх власних фото, а кожен результат чекає на твоє *«Це я?»*. |
| **Наступна покупка** | Річ, яка добудовує найбільше образів і дає найбільше нових поєднань, — з реальними варіантами в магазинах і підказкою, як перевірити посадку. |

## Як це працює

1. **Додай фото** — себе й свого одягу. Кожна річ розпізнається й отримує чисте каталожне зображення.
2. **Обери капсули** та їхні погодні періоди.
3. **Збери набір**: залиш найсильніші речі, познач базу, прибери те, що дає замало образів.
4. **Носи образи** й приміряй їх. Нові образи для капсули не виходять за її набір: нова річ може лише зайняти вільне місце або замінити конкретну.
5. **Купуй те, що важливо**: наступну покупку визначає те, що вона справді додає.

## Принципи

- **Мода понад усе.** Капсулу оцінюють як стиль (виразний, актуальний, вишуканий), а не за тим, що вже лежить у шафі.
- **Спокійний дизайн.** Мінімум елементів, тиха типографіка, усе на виду. Нічого зайвого.
- **Твої фото — твої.** Вони потрібні лише для твого гардероба й примірок. Їх не продають, не передають і не використовують для навчання, а з видаленням акаунта вони зникають.
- **Чесні оцінки.** Ідея ніколи не стоїть вище за те, що можна вдягнути сьогодні.
