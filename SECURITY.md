# Security

Please report vulnerabilities privately to **hello@capsula.fit**, not in a public issue. Say what you found, how to reproduce it and what it affects. We aim to answer within a week and to fix the problem before anything is disclosed.

Capsula keeps people's own photos, so these matter most: one account reaching another's data, getting past sign-in or invitations, and requests that reach the server's private network.

Supported: the latest commit on `main` and the hosted beta at [capsula.fit](https://capsula.fit).
